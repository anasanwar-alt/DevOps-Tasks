==============================================================================
  1. Re-tag the Day 3 image for the local registry
==============================================================================

# The destination registry is encoded IN the image name - there is no
# --registry flag on 'docker push'. Re-tagging is how you retarget.

$ docker tag localhost:5000/day3-hello:multi day3-hello:multi

$ docker images --filter reference='day3-hello' --filter reference='*/day3-hello'

# ^ Note the IMAGE ID column: both names point at ONE image. A tag is a
#   pointer, not a copy - which is why 'docker tag' is instant.

  3. Ask the registry what it now holds (its plain HTTP API)
==============================================================================

# ^ The repository is 'day3-hello', NOT 'localhost:5000/day3-hello'. The
#   host part was routing info; the registry already knows it is itself.

==============================================================================
  4. Record the digest, then destroy every local copy
==============================================================================

$ docker image inspect --format '{{.Id}}' localhost:5000/day3-hello:multi
sha256:c9d21ea1452364dabb94a46df00d2199216b5f629ad57c74370b423e35572581

# Both tags must go. Docker only evicts the image when the LAST pointer
# to it disappears - removing one tag would leave the image on disk and
# make the pull below a silent no-op, faking the proof.

$ docker rmi day3-hello:multi localhost:5000/day3-hello:multi
Untagged: day3-hello:multi
Untagged: localhost:5000/day3-hello:multi
Untagged: localhost:5000/day3-hello@sha256:421f228b05767b0e07af020589c95af4ea48a0d455e05908eb63d7ba4d15b664
Deleted: sha256:c9d21ea1452364dabb94a46df00d2199216b5f629ad57c74370b423e35572581

$ docker images --filter reference='day3-hello' --filter reference='*/day3-hello'
REPOSITORY   TAG       IMAGE ID       CREATED      SIZE
day3-hello   single    1d78503d8c51   4 days ago   220MB

# ^ Only day3-hello:single remains - a DIFFERENT image, untouched.
